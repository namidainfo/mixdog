작업을 선택하고 기록 흐름을 확인

Mixdog Personal의 실제 Worktrail 패널 구조와 Project Workdesk의 비주얼 도구를 바탕으로 한 목업입니다. 모든 작업·시각·기록은 샘플이며 실제 조회·저장·외부 전송을 하지 않습니다. 상태를 비교하기 쉽도록 현황·상세 프레임은 본문 높이에 맞춰 펼쳤습니다. 실제 앱의 패널 스크롤 구조는 유지합니다.

A · 현황과 최근 기록 흐름

기록 순서 흐름에서 종류와 작업을 찾습니다. 막대나 작업을 누르면 목록 대신 선택 작업을 바로 표시합니다.

B · 선택 작업과 기록 확인

선택 작업의 막대를 강조하고 정확한 시각·요약을 표시합니다. 해당 기록과 최근 기록 카드는 세로로 배치합니다.

C · 검색 결과에서 작업 선택

검색에 일치하는 작업의 최근 기록만 표시합니다. 선택 후에는 같은 상세 화면으로 이동합니다.

D · 기록이 없을 때

빈 그래프나 가짜 기록을 만들지 않습니다. 기록이 없다는 안내와 다시 조회하는 행동만 남깁니다.

E · 조회 실패와 마지막 조회 내용

조회 실패를 명시하고 마지막 조회 내용과 최신 상태를 구분합니다. 기존 기록은 지우지 않습니다.

문서화 탭도 눌러 볼 수 있습니다. 초안 버튼은 탭 아래에 고정하고 200개 완료 목록 안에서만 스크롤합니다. 실제 문서 저장·CloudWiki 승인 요청은 이 목업에서 실행하지 않습니다.
